화링고 개인정보처리방침

화링고(Hwalingo) 웹과 안드로이드 앱에서 처리하는 개인정보의 종류, 이용 목적, 보관 및 삭제 방법을 안내합니다.

화링고 계정 및 데이터 삭제 요청

처리하는 정보와 이용 목적

  • 계정 정보 · 이메일 주소, 표시 이름, 비밀번호의 해시값을 회원가입, 로그인, 계정 관리 및 비밀번호 재설정에 사용합니다. 로그인 상태는 세션 쿠키로 관리합니다.
  • 학습 정보 · 선택한 언어, 입력하거나 추출한 문장, 저장한 단어, 퀴즈 응답과 결과, 학습 활동과 시간, 서비스 설정을 분석 결과 제공, 복습, 학습 현황 표시 및 설정 유지에 사용합니다.
  • 사진과 이미지 · 사진에서 글자 읽기 기능을 사용할 때 사용자가 촬영하거나 선택해 제출한 이미지를 문자 인식에 사용합니다.
  • 고객 문의 · 문의 유형과 내용, 가입 이메일 및 표시 이름을 문의 처리와 답변에 사용합니다.

외부 서비스 이용

  • Netlify는 웹사이트를 제공하고 API 요청을 화링고 서버로 전달합니다.
  • OpenAI는 문장 분석, 어휘 설명, 스토리 등 AI 기능을 제공하기 위해 해당 요청의 문장, 단어 및 학습 관련 입력을 처리합니다.
  • Google Cloud Vision은 사진에서 글자 읽기를 요청할 때 제출된 이미지를 처리합니다.
  • 메일 서비스 제공업체는 비밀번호 재설정과 문의 전달에 필요한 이메일 주소와 메시지를 처리합니다.

외부 서비스는 해당 기능에 필요한 정보를 처리하며, 처리 과정에서 정보가 해외 서버를 거칠 수 있습니다.

보관과 삭제

계정과 계정에 연결된 학습 기록 및 설정은 서비스 이용을 위해 보관합니다. 완료되거나 실패한 문장 분석 작업의 입력과 결과는 작업 종료 7일 후 정리 대상이 되며, 별도로 저장한 학습 기록은 계정에 연결되어 유지됩니다.

화링고 계정 및 데이터 삭제 요청

아래 링크를 눌러 화링고에 가입한 이메일 주소에서 계정 삭제 요청을 보내주세요. 본문에 가입 이메일과 계정 삭제 요청을 적어주세요. 비밀번호는 보내지 마세요.

이메일로 화링고 계정 삭제 요청

가입한 이메일에 접근할 수 없으면 현재 사용 가능한 이메일에서 가입 이메일과 상황을 알려주세요. 운영자가 계정 소유 여부를 확인하는 방법을 안내합니다.

직접 삭제하려면 화링고 웹사이트나 앱에서 로그인한 뒤 마이페이지 → 계정 관리 → 회원 탈퇴에서 비밀번호를 확인하세요. 계정 삭제가 완료되면 계정 정보, 단어장, 퀴즈 결과, 학습 기록과 설정 등 계정과 연결된 데이터를 삭제합니다.

보안 및 이용자 권리

화링고는 HTTPS를 사용해 정보를 전송하고, 비밀번호는 해시값으로 저장합니다. 마이페이지에서 표시 이름과 비밀번호를 변경할 수 있습니다. 개인정보의 열람, 정정, 삭제 등에 관한 요청은 아래 연락처로 접수합니다.
